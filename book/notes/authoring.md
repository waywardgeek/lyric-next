# Codebook authoring agreements

## Improve the language while constructing it

Bill explicitly authorizes Cadence to identify and propose language changes that clearly simplify construction or testing of this codebook. Explain the concrete benefit, tradeoffs, and any changed semantics while Bill can steer. Once Bill approves, implement the change immediately within that agreed scope; do not ask again for routine implementation permission or defer it merely because an earlier chapter is already complete.

Update the language specification, the original construction chapter(s), exercises, and independent retained graders together. Teach the construction where the next book execution needs it, rather than leaving a patch diary or a feature found only in the current compiler. Preserve historical verification claims and successful frozen student results; new changes are not retroactively tested by those runs and do not authorize rerunning a passing student.

This permission is specific to work on this codebook. It does not authorize unapproved language redesign, deployment, or unrelated work.
